# Workflow Diagram Images

Place your generated workflow images here:

- `rag-workflow.png` - RAG (Semantic Search) system diagram
- `memory-workflow.png` - Memory system (mem0) diagram  
- `mcp-workflow.png` - MCP tool integration diagram
- `full-architecture.png` - Complete system architecture (optional)

## Image Specifications

- **Resolution:** 1920x1080 (16:9)
- **Format:** PNG or SVG
- **Max Size:** 1MB per image
- **Background:** White or transparent

## Usage in README

These images will be referenced in the main README.md:

```markdown
![RAG Workflow](./docs/images/rag-workflow.png)
![Memory Workflow](./docs/images/memory-workflow.png)
![MCP Workflow](./docs/images/mcp-workflow.png)
```

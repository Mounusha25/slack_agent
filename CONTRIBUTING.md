# Contributing to SlackMind

First off, thank you for considering contributing to SlackMind! 🎉

## Ways to Contribute

### 🐛 Bug Reports
- Use GitHub Issues
- Include reproduction steps
- Provide system information (OS, Node version)
- Share relevant logs

### ✨ Feature Requests
- Check existing issues first
- Describe the use case
- Explain why it's valuable
- Consider implementation complexity

### 💻 Code Contributions
- Fork the repository
- Create a feature branch
- Write clean, documented code
- Follow existing code style
- Add tests if applicable
- Update documentation

## Development Setup

```bash
# Clone your fork
git clone https://github.com/YOUR_USERNAME/slack-ai-assistant.git
cd slack-ai-assistant

# Install dependencies
npm install

# Copy environment template
cp .env.example .env

# Fill in your API keys
nano .env

# Run in development mode
npm run dev
```

## Code Style

- **TypeScript**: Strict mode enabled
- **Formatting**: 2 spaces, semicolons
- **Naming**: camelCase for variables, PascalCase for types
- **Imports**: ESM modules, explicit extensions (.js)

## Pull Request Process

1. Update README.md if needed
2. Update CHANGELOG.md with your changes
3. Ensure tests pass (when available)
4. Request review from maintainers
5. Squash commits before merging

## Code of Conduct

- Be respectful and inclusive
- Focus on constructive feedback
- Help others learn and grow
- No harassment or discrimination
